# mfayaadh.github.io

Personal portfolio of **Muhammad Fayaadh** — <https://mfayaadh.github.io/>

Plain HTML, CSS and JavaScript. No framework and no build step: open `index.html` or serve the folder with any static file server.

`tools/` holds optional helper scripts (layout checks and image generation) that need Node.js and Chromium. The site does not depend on them.
